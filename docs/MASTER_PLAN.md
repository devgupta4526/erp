# BusinessOS master plan

Keep one application and integrate workflows in the sequence below. See [implementation progress](IMPLEMENTATION_PROGRESS.md) and the [feature register](FEATURE_PARITY.md).

1. Pin upstream revisions, inspect workflows and record licensing constraints.
2. Establish the application, database migrations, identity, organization membership, subscription access and deployment packaging.
3. Extend shared engines for CRM, billing, inventory, documents, staff, scheduling and reporting.
4. Deliver the gym workflow through membership, attendance, payment and reporting. Continue with the source-verified modules in the [module map](MODULE_MAP.md).
5. Add specialized processing as workflow requirements justify it.
6. Run the full verification pass when testing is authorized. Verify backups, recovery, HTTPS and resource consumption before commercial release.
