# BusinessOS

BusinessOS is a modular, multi-tenant ERP built with Next.js, TypeScript and PostgreSQL. The current implementation includes workspace administration, local subscription simulation, inventory, scheduling, sales invoices, CRM, Gym, Hotel, Courier and Learning workflows.
